## 👋 About me

I am a software engineer at **[Cefalo](https://www.cefalo.com/en/about-us)** in Dhaka, Bangladesh, building
and running software for Norwegian product teams. Today I work on the **gateway, edge and Kubernetes
platform** behind a high-traffic news publisher. Before that I built **Java, Kotlin and TypeScript
backends** for an archive platform, a hotel management system and an applicant tracking system.

On the side I do **applied machine learning research**, and I am preparing for graduate study in AI
and software systems. My research interest is **AI agents for cloud operations**: making systems like
the ones I run every day easier to operate and more reliable.
